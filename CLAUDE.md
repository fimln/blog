# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

**Serve locally (native Ruby, recommended in WSL2):**
```bash
bundle exec jekyll serve --livereload
```
Runs on `http://localhost:4000/blog/`. Docker-based `run.sh` requires Docker daemon, which is not available in this WSL2 environment.

**Build (no serve):**
```bash
bundle exec jekyll build
```

**Install/update gems:**
```bash
bundle install
```

There are no tests or linters in this project.

## Architecture

This is a Jekyll blog using the [Hydejack](https://hydejack.com/) theme v9.2.1, vendored directly into the repository (not via remote_theme or gem). All theme files live in `_layouts/`, `_includes/`, `_sass/`, and `assets/` alongside the site content.

**Key configuration:**
- `_config.yml` is the single source of truth for site metadata, author profile, Hydejack feature flags, plugins, and permalink structure.
- `baseurl` is `/blog` and `url` is `https://fimln.dev`, so local links must account for the subpath.
- Accent color: `#D97757` (terracotta/clay). Sidebar/page background: `#FAF9F5` (warm cream). Both set via `accent_color` and `accent_image.background` in `_config.yml`. Dark mode uses `#1F1E1B` body background with `#E89876` accent.

**Styling:**
- The pre-built CSS is at `assets/css/hydejack-9.2.1.css`. Do not edit this file.
- Custom SCSS overrides go in `_sass/my-variables.scss` (variable overrides) and `_sass/my-style.scss` (structural overrides). These files are imported by Hydejack's style pipeline automatically.
- Per-page inline style overrides go in `_sass/my-inline.scss`.

**Dark mode:**
- Enabled via `hydejack.dark_mode.dynamic: true` and `hydejack.dark_mode.icon: true` in `_config.yml`.
- System default is detected automatically via `@media (prefers-color-scheme: dark)` (CSS) and `matchMedia` (JS).
- The toggle button in the navbar persists the user's choice to `localStorage` via `_includes/pro/dark-mode-fix.html` (applies saved class at top of body, no FOUC) and `_includes/my-scripts.html` (listens for `hydejack-dark-mode-toggle` event and writes to `localStorage`).

**Content:**
- Posts go in `_posts/` with filename format `YYYY-MM-DD-title.md` and front matter `layout: post`.
- The homepage is `index.html` with `layout: blog` (paginated post list with `cover: true`).
- The about page is `about.md` with `layout: about` and `menu: true`.
- Navigation is configured via the top-level `menu:` list in `_config.yml`.

**User override hooks** (Hydejack's extension points):
- `_includes/my-head.html` - injected at end of `<head>`. Currently: favicon links.
- `_includes/my-body.html` - injected at bottom of `<body>`. Currently empty.
- `_includes/my-scripts.html` - injected after Hydejack JS loads. Currently: dark mode localStorage persistence listener.
- `_includes/my-comments.html` - comments provider integration. Currently empty.
- `_sass/my-variables.scss` - SCSS variable overrides.
- `_sass/my-style.scss` - additional CSS rules.

**Excluded from build:** `vendor/`, `.bundle/`, `node_modules/`, and standard Jekyll cache dirs are excluded in `_config.yml` and `.gitignore`. `Gemfile.lock` is gitignored.
